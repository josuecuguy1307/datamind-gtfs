# Contributing to ML DataMind

Contributions are welcome: bug reports, fixes, tests, documentation, translations
and new integrations.

## How to contribute

1. Open an issue to discuss a change, or go straight to a pull request for small
   fixes.
2. Run the relevant tests before you send it. Run the suites one folder at a time;
   the README lists them.
3. Keep data and secrets out of your change: no real datasets, `.env` files,
   credentials or personal paths. `python tools/secret_scan.py --tracked` checks
   the tracked files.
