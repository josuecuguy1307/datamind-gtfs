# Versions and licenses

ML DataMind changed licenses once. This page says which license covers which
version, so nobody has to guess.

| Versions | License | Where to find the text |
|---|---|---|
| Everything published through commit `33d2b20` (public `main` on 13 October 2026), which is version `0.1.0` in `datamind_console/__init__.py` | **MIT License** | [`LICENSE-MIT`](../../LICENSE-MIT), or `git show 33d2b20:LICENSE` |
| The commit that adds the new `LICENSE`, and everything after it | **ML DataMind Sustainable Use License** (draft) | [`LICENSE`](../../LICENSE) |

The versions released before the change remain available under the license that
applied to them. The change is not retroactive: nothing here removes, shortens or
conditions a right that the MIT License already granted for those versions.

## What this means in practice

- **Anyone who already has a copy** from the MIT-licensed period keeps the rights
  the MIT License gave them for that copy, including the right to keep using and
  modifying it.
- **Earlier versions stay available** in the repository history. The project does
  not rewrite the history, and no tag or release has been deleted (none existed).
- **New work** based on the versions after the change is covered by the new
  license.
